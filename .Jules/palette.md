## 2023-11-04 - Screen Reader Accessibility on Custom Clickable Components
**Learning:** `clickable` modifier in Jetpack Compose without `onClickLabel` or `role` results in poor experience for screen reader users as they do not announce what the action does, only that it is a button/clickable. In a custom component like `CountrySelector` where the clickable area wraps complex UI (Icon, text flags, name), specifying `onClickLabel = "Sélectionner un pays"` gives exact context of the action. This was especially apparent for the items in the lazy list where `onClickLabel = "Sélectionner ${country.name}"` makes navigation much clearer.
**Action:** Always provide an `onClickLabel` with clear action verbs (like "Sélectionner", "Ouvrir", etc.) to `clickable` modifiers on generic components (like `Box` or `Row` acting as buttons) so screen readers give descriptive feedback.
